# crown-relay — Спека

Канистра ICP: разрешённый вызывающий делает `submit` **без циклов**; релеер форвардит в индекс/игру,
прикрепляя `INGEST_PRICE`/`SIGN_PRICE` из бюджета (3% комиссий). Один фронтер на всё: вписи сеттлментов,
вписи рождений, запросы подписи игр (`00-architecture.md §6`).

## Поверхность (`.did`)

**Единственный не-`query`:**
- `submit(Request) -> SubmitResult` — `Request = variant { Settlement:sig; Birth:sig; Sign:SignReq }`.
  Порядок (всё — до любой траты): `inspect_message` (allowlist + размер) → allowlist(`msg_caller`) →
  per-key rate-limit → пол `balance ≥ CYCLE_FLOOR + цена` → форвард с прикреплёнными циклами.
- `get_index() -> principal` (`query`).

Дедупа релеер не ведёт: повтор применённой вписи индекс отбивает **до** приёма циклов и рефандит.

## Правило подписи (не-отрицательность, `cost.md §6`)

Перед `Sign` бэкенд платформы вычисляет окупаемость области и шлёт `submit(Sign)` **только** для
проходящих: `f·Σgross_нового ≥ scope_cost(V_MAX)·(1+MARGIN)` — на **каждую** подпись, включая
инкрементальные (форма `stream`; у `two-outcome` пере-подписей нет — #4 снят структурно, `games-harness §5`).
Не проходит → не подписываем → эскроу возвращаются ончейном, платформа платит $0. `scope_cost` считается
по `V_MAX`, не текущему `V` (инвариант **#5**, анти-TOCTOU).

## Управление и бэкстоп

Не заморожен. Allowlist — пушеры платформы; `index` — principal `crown-indexer`; бюджет пополняется из
комиссий. На mainnet override init запрещён (trap). **Цензуростойкость** — бэкстопом индекса/игр:
`ingest`/`request_signature` пермишенлес-платные, любой со своей бюджетной канистрой платит мимо релеера.

## Не-отрицательность (владелец: `cost.md §6`)

- **#5** `scope_cost` по `V_MAX` (анти-TOCTOU): правило подписи на **каждую** подпись + батчинг клеймов.
- **#6** per-key rate-limit/cap: утёкший ключ деградирует, не сушит бюджет.
- `inspect_message` отсекает не-allowlisted/переростков до исполнения (бесплатно) — общая защита периметра релея, не нумерованный инвариант `cost.md §6`.

## DoD / тесты (`01-standards §Тесты 11,12`)

`.did` — только `submit` не-`query`. Не-allowlisted не тратит и не меняет состояние. `inspect_message`
отсекает до исполнения. Per-key cap: один ключ не сушит бюджет за окно. Пол по циклам до форварда.
`INGEST_PRICE`/`SIGN_PRICE` релея ≥ индексных/игровых. Override на mainnet-профиле трапает.
